# Amazon-Prime-EDA

🔗 **Colab Notebook Link:** [Open in Google Colab](https://colab.research.google.com/drive/1f08-7r381B-UY0jMdStqOFtQMxzTmWD7?usp=sharing)

This project analyzes Amazon Prime Video's content catalogue (titles + credits)
to find trends in genres, ratings, and content growth over time.

## Problem Statement
Amazon Prime Video's content library is constantly growing. This project explores
the dataset to understand content diversity, regional availability, trends over
time, and IMDb/TMDb ratings, in order to generate insights useful to content
strategists, marketing teams, and investors.

## Dataset
- `titles.csv` - ~9.9K unique titles with metadata (genre, release year, ratings, etc.)
- `credits.csv` - ~124K actor/director credits for those titles
